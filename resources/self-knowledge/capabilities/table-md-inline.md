Markdown 文档里的表格会显示成排版好的网格（表头、左 / 中 / 右对齐、格内粗体 / 代码 / 链接 / emoji 正常渲染）。点一个格进编辑、失焦或回车提交、Esc 取消、Tab 跳下一格；鼠标移到行列边缘浮出「+」插入、点列头 / 行首删除；拖两列交界改列宽。增删改都进 ⌘Z 撤销栈。

**限制**：不做合并单元格 / 跨行跨列，不做格内换行。列宽不写进文件（关闭重开按内容自适应）。不做排序 / 筛选 / 求和（那是 CSV 表格的事）。手打一个新表要敲完第二行的对齐行那一刻才成形为网格。

**怎么用**：在 md 文档里点表格的格子直接改，移到边缘加减行列。这和 CSV 表格视图是两回事——这条是文档**内嵌**的小表格。
