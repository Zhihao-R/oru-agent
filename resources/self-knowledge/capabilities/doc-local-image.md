在文档正文里 ⌘V 粘贴剪贴板里的图（系统截图、飞书右键复制的图、网页复制的图），或从访达把图片文件拖进正文——图片字节会写进文档旁边的 `.assets` 文件夹、插入相对引用并当场渲染成缩略图。选中图后能拖四角调显示尺寸、进裁剪框矩形裁剪、设左 / 居中 / 右对齐。改名或移动文档时 `.assets` 会一起原子搬走，删文档连图一起进回收站。

**限制**：大小和对齐只能落成 HTML——飞书等外部渲染器打开时不保真，会优雅降级为原始大小左对齐（图不消失）。裁剪是破坏性的（写一张新图，原图仍留在 assets）。不做文字环绕 / 题注 / 滤镜 / 旋转；不自动下载远程图片 URL；没有"插入图片"按钮，只靠粘贴和拖入。

**怎么用**：光标放在正文里粘贴或拖入图片即可；选中已插入的图出现手柄和工具条做缩放 / 裁剪 / 对齐。
