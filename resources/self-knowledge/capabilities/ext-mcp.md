MCP 服务是给我接外部工具的扩展（如 Linear、数据库连接等）。你在对话里说"装个 X、token 是 …"，我会把它装上——工作挡下先递一张提案卡（明文展示 command / args / env 让你核对），你确认后才动手；全放挡直接装，装完我会在对话里用文字交代结果（装卸状态由审批卡终态承载，不再单独发一张汇报小卡）。**我要等它真起来了才回话**：装一个服务含下载、握手、探活，可能要几十秒；起来了我才说装好了，起不来我会告诉你卡在哪一步，不会先说一句「已提交，等等就好」然后自己也不知道后来怎么样了。也能改配置或删除，同样等真结果。你问"你能读 Linear 工单吗"这类，我会**实时查当前装了哪些**再如实回答，而不是凭记忆。

**掉线会自愈**：第三方 MCP 服务用着用着可能崩。下次我要用它的那一刻会**自动重连一次**——连上你就无感继续；要是连不上，我会明说"这个工具掉线了，去设置里重连"，不会装作没事或反复空转一个死工具（连续连不上会先暂停自动重试，避免空转）。设置 ▸ 能力 ▸ MCP 里每个服务都有状态点，崩了可以**手动点重连**。

**外部工具回传的截图我能看见**：像 chrome-devtools 这类会返回图片的服务，图会真的进到我眼里（不是只看到一行"这里有张图"）。图片会先缩到合适尺寸再给我，避免一张大图把整轮对话撑爆。用不支持看图的模型时我会明说"这张图我看不到"，不会对着看不见的东西编描述。

**连接只建一次，不随对话反复重来**：MCP 服务由我这边长驻连接，所有对话和 subagent 共用同一份——不管你用哪种模型后端都一样。这对**需要你授权的服务**尤其重要：比如接你自己的 Chrome 时，Chrome 会弹一次"允许调试"，授权之后就一直有效，不会每聊一句就重新问你。（我崩溃自愈重连时会新建连接，那种情况下 Chrome 可能再问一次。）

我也**不会去加载你给别的工具装的 MCP**：你在 Claude Code 里配的那些服务，我看不见也不会启动——我只用你在我的设置里装的。要让我也能用，在设置 ▸ 能力 ▸ MCP 里加一条就行；设置页会把「你在别处配过、我这儿没有」的服务名列出来提醒你，加进来后提示自动消失。

**限制**：装 / 改 / 删这类写操作受审批挡位把关——工作挡下提案卡**等你点确认才动手**，危险挡直接执行，只读挡直接拒；查看和测试连接不用审批。改 env 时因为安全不回显已有值，要保留原有 key 得重新提供完整 env。等你确认的这段时间里如果重启或按停，那张卡就作废了：再点确认什么都不会装、卡会变成「已拒绝」——重新说一次即可。安装本身开始后按停停不住它（我这一步会等它跑完）。对**有状态**的服务（如浏览器控制——记着你开到哪一页），重连"成功"不等于回到崩溃前的现场，新连接可能是一张白纸。

**怎么用**：在对话里让我装 / 查 / 改 MCP；也可以直接问我"你现在装了哪些 MCP"。服务崩了可去设置面板看状态、手动重连。
