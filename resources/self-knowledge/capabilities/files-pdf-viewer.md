在文件树里双击 `.pdf` 就在右栏开一个标签页，和看 md、表格一样是一家人，不用切出去用别的应用。页面连续垂直滚动翻，顶部工具栏能看当前页 / 总页数、点页码直接跳页、缩小放大调百分比、一键「适配宽度」回正；⌘F（或点搜索图标）唤起搜索条，输入词全文高亮命中并显示计数，Enter / Shift+Enter 在命中间前后跳。可以用光标划选 PDF 里的文字（能跨页连选），⌘C 复制为纯文本——复制后粘进对话就能让我就这段文字讨论。缩放支持工具栏按钮、⌘+ / ⌘− 和触控板双指捏合三种方式；高分屏下缩放后文字依然清晰。

**限制**：本期只做「看」——**不能在 PDF 上批注 / 圈画**（md 和 deck 能批注，PDF 还不能），**不能编辑**（PDF 是只读的，不进实时保存 / 修改历史，改不了内容）。选中文字点「引用进对话」那类联动也还没有，取内容只能靠划选复制。受密码保护的 PDF 打不开（会提示暂不支持）；扫描件（纯图片的 PDF）能正常显示但没有字可选、搜不到。

**怎么用**：文件树里双击 `.pdf` 打开即可；对话里的文件 chip 也一样——我生成 / 改过 PDF 后，「本轮文件变更」条、工具详情浮层、正文路径 chip 上的 PDF 都能点击直接在右栏打开。我读 PDF 内容是另一回事、早就能做——你让我「读这份 PDF 总结一下」我走文本抽取就能读，和你自己在查看器里看是两条独立的路。
