在文件树侧栏点「+」就能新建文件，当场起名、回车即创建并打开。

**限制**：只提供三样——Markdown 文档、CSV 表格、文件夹（不做 txt / html / 图片）。新建 CSV 会给一张有表头的最小起步空表，md 是白纸。你亲手起的名字若撞名会当场红字提示让你改、绝不静默覆盖。

**怎么用**：点「文件」标题行右侧的「+」选类型，或在文件树里右键文件夹 / 空白处新建；落点跟随当前选中（选中文件夹就建在里面，选中文件就建在同级）。
