对一个有明确达标标准的任务，可以套一个收敛循环：我对照一份可核验的验收标准反复干到达标，干活和验收分开。

**干活在主对话里可见**：每一轮我就在主对话流里实际动手——你看得到我的消息、我调的工具、我做出来的东西，跟平常对话一样。要不要为某块活派 subagent 由我自己决定。不是后台黑箱，你全程看得见。

**验收交独立审查员**：每轮干完，一个独立、无记忆、也没有工具的审查员会读这一段对话的完整记录，逐项判「达标 / 没达标」。它只认真正摊在对话里的证据（做出来的产出、跑过的验证）——我口头说「我做到了 X」不算数；证据不够它就判没达标，并说清还缺什么，好让下一轮补上。

**常驻条**：跑起来时输入框上方会出现一根常驻条，收起时一行告诉你第几轮、几项达标；点开能看到全部验收标准逐项达标没达标，点某一项能看它的打回理由，也能在这里给标准加一项。干活过程本身在对话流里，条只做进度呈现；循环结束后它还会陈列一会儿终态，你再发一条消息就自动收走。

**拆完直接开跑**：我把目标拆成一份验收标准后就直接开始，不再先摆给你逐条确认。方向拆偏了，靠你中途改标准或叫停来兜——省掉每次开工前的过目。目标可以承接当前对话——「继续把刚才那批筛完」这类带指代的说法也行，拆标准时我看得到最近的对话。

**可以带图**：发 /loop 时贴的图，我拆验收标准时看得到，之后每一轮干活也看得到——跟平常发图给我一样。图里的要求我会拆成文字判据（具体的列名、要点、数值），因为验收的审查员只读对话文本、看不到图。想在「继续」的新循环里接着用图，在那条消息里重新贴一次。

**目标太模糊时我会反问，不报错**：目标拆不出「算完成了没」的判据（开放问题、纯探索、缺关键信息）时，我不硬开跑，而是在对话里直接问你一个具体的问题——常驻条上标「没开跑」，你补一句再发一次 /loop 就行。

**跑起来后你有两种介入**：
- **停**：跟打断平常回合同一个动作（Esc / 停止当前回合）就能停掉整个循环；当前这一轮收尾、已经达标的部分保留，常驻条上标「已停止」。
- **改标准**：中途发现漏了，点开常驻条能加一项——下一轮就按新标准走。改标准不会把轮数清零（上限管的是这一次总共花多少）。

跑的过程里你在对话里说的话，会作为这一轮的引导一并喂给我——轻轻点一句就能影响下一轮的方向。

**收敛后再汇报一轮**：验收标准全达标后，我会以审查结果为引导，用平常对话的口吻跟你说一声这次做了什么、达成了什么。

**跨重启**：循环跑到一半应用关了，重开会认出「有个循环没跑完」，那个对话的常驻条会陈列中断态——停在第几轮、哪些达标了都在上面，不会自己偷偷续上，也不弹窗问你。想接着做，就再发一条带 Loop 标记的「继续」：我看得到中断时的进度，会接着上次的进展重新拆一份标准开跑（新循环、轮数重新计）。

**轮数上限可调**：默认最多跑 5 轮，可以在设置里改（想磨得更狠调大、嫌费钱调小）；到上限还没全达标就停下、把现状交给你。

**限制**：统一手动触发，不会替你偷偷一直跑。列不出可核验标准的漫无目标探索不适用。演示稿自带的轻量质检不是这个 Loop 模式（那个是自动跑的、另一套）。

**怎么用**：在输入栏用「/loop」命令或对应按钮触发，跟上你要循环的任务。
