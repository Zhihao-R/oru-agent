你可以用三挡审批控制我做事前要不要先问你：🔵 只读（能看不能改——读文件、搜索、看网页照常，改东西不自动执行，个别如新建演示稿会弹卡请你亲自定）、🟡 工作（破坏性操作与对外投递才问，日常主力）、🔴 危险（全放手）。挡位实时生效，决定我改文件、装 MCP / 插件、跑命令这些写操作弹不弹确认卡。

确认卡按**行为**说话，不按工具：标题写我要干什么（「覆盖既有内容」「删除内容」「访问网站」「发送内容到外部」「变更系统环境」「创建自动化任务」「破坏性命令」「看不透的命令」），下面写具体对象（哪个文件、哪个网址、发给谁）。卡片给三个选择：**允许**（仅此一次）、**始终允许**、**拒绝**。「始终允许」按钮上会写清你授权的是什么、到什么粒度——「始终允许：覆盖既有内容（整类）」是这一类以后都不再问；「始终允许：向 飞书：研发群 发送」只对这一个收件人免卡。授权记进一份持久清单，**设置 ▸ 权限与行为**里有一张完整的「权限策略表」：每一类行为问不问一目了然，开关是**双向**的——默认问的行拨开就免卡、拨回恢复询问；默认不问的行（新建 / 修改内容、覆盖我的自产文件）也能拨成「每次问」。已允许的收件人逐条可撤——它是你了解「我实际被放行到哪一步」的唯一窗口。

几类行为的边界值得知道：

- **访问网站**（抓 / 打开我自己找到的网址，不是你逐字给的链接）：默认问，可整类免卡——点一次「始终允许」，以后所有自拟地址都不再问。代价是「网址里夹带数据」这道确认也随之消失，授权前想清楚。
- **发送内容到外部**（curl / ssh / 飞书命令行发消息等把本机内容送出去）：默认问，按**收件人＋渠道**授权——发给研发群的授权不覆盖发给任何人。策略表上另有一个**总开关**（默认关）：拨开后所有外发——包括没见过的收件人——都不再问，等于把外发这一类的把关整个交出去，开之前想清楚。你在消息里贴过的地址不算外发，我直接用。
- **看不透的命令**（含命令替换、eval 等我判不出结构的命令）：我当危险处理、默认问，但和「破坏性命令」是两个独立的类——授权破坏性不会连带免掉看不透的。灾难级（`rm -rf /`、抹盘、格式化）永不可授权，每次都问，策略表里是锁定行。
- **删除与编码转换**：删除走系统回收站（可恢复），编码转换会整篇重写字节（原版进修改历史）——两者都默认问、都可整类免卡；编码转换的卡上另有一行不可逆警示。
- **装卸与自动化**：装 / 改 / 删 MCP、插件、装 Skill，以及定时任务的新建 / 修改 / 删除·暂停·启用，工作挡都是等你点了确认才动手，各自可整类免卡。

第一次跑命令**不再**弹「启用命令执行能力」卡（那层能力审批已取消）——跑命令和用其它工具一样，只看行为该不该问。

工作挡的「覆盖时问」有一个例外：我反复打磨**自己刚产出的文件**（比如迭代一份 deck、多轮重写一篇长文）时不会每次都问——只要这个文件从我整篇写出以来你没动过，覆盖它不会毁掉你的内容。你改过之后我再想整篇覆盖，照旧先问你。这道免审在策略表里也有开关（「覆盖 Oru 自己的产出」，默认开）：拨关后我连自己的产出被覆盖也要先问你。

派工是另一回事：把任务派给 subagent 这件事本身**任何挡位都能做**——但派出去的 subagent 继承当前挡位，它想写文件、跑命令时每一步照样过闸（只读挡下它只能看不能改）。

确认卡只记**决定**、不复述执行：你一点，它就落定为「已批准 / 已拒绝」——执行的过程与成败在对话流里自有呈现。「谁在什么时候批了什么」会作为审计存证落盘，重启不丢。拒绝时可以顺手写一句**附言**说明为什么不批，我下一轮会看到，据此换个做法，而不是重复递同一个提案。

还有一道跟挡位无关、始终在岗的**断路器**（像电闸过载跳闸）：一个回合里我要是卡进死循环——同一步反复失败还在重试，或短时间内工具调用异常频繁——会自动暂停，弹一张卡让你「继续放行」或「停止」，免得我无声烧钱、反复写盘。

**限制**：危险挡仍有一道"火灰断路器"——灾难级操作强制弹红卡，拦不掉。危险挡的直通**不会**把授权永久记下来，切回工作挡后该问的还是会问。权限策略表**只在工作挡可见可调**：只读挡（能看不能改，规则内建）与危险挡（除灾难级全放行）下不显示这张表，只留一行当前挡位的说明。挡位是**全局单一**的（不分对话），默认工作挡；在设置或任何对话里改挡，所有对话即时生效。

远程也能审批：对话绑定了飞书时，同一张确认卡会以飞书互动卡片送到你手机上——允许 / 始终允许 / 拒绝都是可点的按钮，点了就地回流、和桌面**先到先得**（谁先点谁生效）。飞书上点「始终允许」跟在桌面点是同一份清单、同等效力。（Discord 目前还没接按钮，远程遇到要审批的操作会先拒绝并回一句提示，让你换挡或回桌面处理。）

**怎么用**：在「设置 ▸ 权限与行为」里选挡位、拨各类行为的免卡开关、撤销已允许的收件人；也可以在对话里跟我说切哪一挡；在飞书 / Discord 远程时发 `/mode danger｜work｜readonly` 也能切（改的是同一个全局挡位）。
