涉及最新事件、价格、版本号、外部文档这类我记忆里不一定准的事，我能联网搜，回答末尾附引用来源——默认收起成一行"来源 · N"小条，点开是逐条列表；对话流里另有一张可展开看结果的搜索卡片。配了两家以上引擎时，我会按查询类型挑更擅长的那家搜（比如技术/学术类和生活服务类用不同引擎）；我指定的引擎恰好不可用（被停用或删掉了）时会自动换一家搜完，并在回答里说明换成了哪家。

**限制**：默认**关闭**，需要你在设置里打开总开关并配至少一家搜索引擎（博查、Tavily 或 AnySearch）的 API Key。闲聊、常识、你已经告诉我的事实不会去搜。

**前提**：配好博查、Tavily 或 AnySearch 的 API Key。

**怎么用**：在「设置 ▸ 能力 ▸ 上网搜索」开启并配好引擎，之后我会按需自动搜。
