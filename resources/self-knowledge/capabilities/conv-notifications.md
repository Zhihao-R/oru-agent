右上角「oru」点开是通知中心，汇集正在跑和已结束的对话与定时任务，按"要不要你管"分三段：**需要你处理**（置顶：问你意见 / 要审批 / 报错 / 错过的定时）、**已完成（待验收）**、**进行中**（带实时进度，可停止）。每条能就地处理（回答 / 接受 / 拒绝 / 看改动 / 重试 / 执行 / 忽略），整条点击打开对话。按钮角标显示"需要你处理"的条数（含下面说的系统信号），没事时只留一个呼吸点。

这些窗口内的圆点和角标只对开着应用的你有效。**你切到别的应用、Oru 不在前台时**，"需要你处理"的事会升级成**系统通知**弹出来（点一下直接跳回对应对话），程序坞图标上也会挂一枚数字角标显示还有几件事没处理——你回到应用、它重新在前台时角标自动清掉。计数和窗口内那枚角标是同一份判定，口径一致。（你离开电脑时通过飞书 / Discord 等渠道主动找你，是更靠后的能力，暂时还没有。）

通知中心最上面还会单列一段**系统信号**——那些不归任何一条对话、但会让我整个人干不了活的事：凭据过期、写盘失败、定时调度停摆、存储损坏。这类信号不进对话列表（那里是「哪条对话有事」），但计入右上角「oru」按钮的数字角标，点开通知中心就能看到。凭据类会随连上恢复自动消失，恢复后再失效会重新提示；写盘 / 调度 / 损坏类是一次性事故，你可以忽略——忽略后同类事故本次运行内不再重复提示（重启后重新计），不是每次发生都弹。

**限制**："已完成"是个待验收收件箱——在哪点开看过就移除，不想点开也可以按「忽略」划掉（划掉即算看过，之后有新动静照常再提醒）。一条对话同时有两件事时只出现一次。本期的「重试」只是打开对话续一句，不是真原地重跑。定时任务的开关启停不在这里管（去定时任务页）。错过的定时任务只有绑定在某条对话上运行的才会顶到「需要你处理」；每次新开独立对话运行的错过任务在定时任务页的「未能触发」区看。

**怎么用**：点右上角「oru」查看，系统信号和需要你处理的事都顶在最上面。
