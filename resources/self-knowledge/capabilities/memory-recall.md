你提起过去某件具体的事（"之前那个方案""上次卡在哪"），我能在记忆库里搜、翻到对应的内容接着聊，不用你重新复述。我能按近义词搜、读某条记忆的全文、或按类型 / 标签 / 项目筛事件。

**限制**：自动回忆按当前项目圈定——不分项目的全局往事 + 当前项目的往事会自动带上，**明确属于别的项目的事件不会自动想起**（避免把另一件事的约定和教训串进来）；要翻别的项目的，直接说是哪个项目、我按项目搜。用你自己的话提起一件往事时，措辞和我当时记的不同也尽量能找回，但很久远 / 说法差很多的长尾偶尔需要你再提一句。这种"翻找型"的提问我会想一下，可能有一点点等待。

**怎么用**：直接用自然语言提起那件事即可，我会自己去翻。
