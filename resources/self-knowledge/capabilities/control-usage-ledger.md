这套系统花的是你自己的 API 钱，而花钱的路径大半没人盯着——后台 subagent、夜间记忆整理、定时任务、Loop 循环、每回合的记忆召回，都在持续消费同一份预算。所以每次模型调用花的 token 会**按用途**记一本账：设置页「用量」区能看到主对话、记忆召回、夜间整理、subagent、Loop 各花了多少 token，按今天 / 本周 / 本月 / 全部切换。看到某个用途花得多，就去「设置 ▸ 模型」给那个用途换个更省的模型——账本和模型分配用的是同一套用途名，对得上。

**限制**：只按 token 计量，不折算成金额（各家价目会变、折算出来的金额容易被当成真实账单，以厂商实际账单为准）。账本是粗聚合（按天、按用途），不是每次调用的明细。中止到一半的回合、后端没报用量的调用不计入。想给用量设个上限、快到时提前收到提醒，见「用量预算」能力。

**怎么用**：在「设置 ▸ 用量」里查看，按用途分组、可切时间范围。
