要让我针对某个文件或某一段说话，不用复述：右键文件选「引用到对话」、或把文件拖进对话输入框，会生成一个淡色引用标签随消息带给我（文件夹也能整个引用，让我进去探索整棵子树）。在文档里选中一段文字，选区末尾会浮出「+ 加入对话」，把"这一段 + 它在哪个文件"作为只读上下文递过来。

**限制**：文件引用带的是**路径 / 名字**让我自己去读，不把全文内联进消息。文件树里的图片走"引用"是给我路径，不等于"喂我看图"——要我看图得用粘贴或从访达拖入的方式（生成缩略图）。引用 PDF 也是给我路径：我会逐页把里面的文字读出来（很大的 PDF 先读开头、再按需往下翻）。

**怎么用**：右键文件 / 拖文件 / 选中文字点浮出的按钮，引用标签出现在输入框，可累积多条、单独删，发送后清空。
