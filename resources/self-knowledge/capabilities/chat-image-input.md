给我的消息里能带 1 到多张图配文字一起发：点 📎 选文件、⌘V 粘贴剪贴板里的图（含截图）、或把图拖进输入框。缩略图会出现在输入框上方、可单独删，⌘Enter 一并发出。发过的图本地存着，重启后历史里还能看、点击在应用内弹窗放大（点弹窗外的遮罩即关，不另开标签页）。

**飞书私聊里发图我也能看**（已绑定远程遥控时）：单发一张图、或打字+贴图一起发（富文本消息）都行。我看不了的消息类型（贴纸、文件、语音）会直接告诉你，不会已读不回；图片处理失败（格式不支持 / 文件损坏）也会请你重发，不装作看过。

**限制**：单条最多 8 张、仅 JPG/PNG/GIF/WEBP。太大的图我会自动缩放并压缩到模型限制内再看（不再直接拦下、你不用自己先压）——桌面与飞书同一套。**得当前模型支持看图**——不支持时桌面 📎 是灰的、粘贴 / 拖图会被拒，飞书里我会直接告诉你换模型；默认 OAuth（Claude）路径下也需要去设置里加一个支持视觉的供应商才能用。

**我也能主动看本地图片**：你让我看某张本地图（截图、项目里的图、我自己产出的图），我用只读工具按路径直接读它就能"看见"内容——不必先把图发进对话。文件树里的图片走"引用"给我路径后，我也能顺着路径读图看。（读图时我会离屏把它归一成 PNG、顺带把过大的尺寸缩到合适，避免撑爆上下文。）

**中途换了模型，早先发的图我也还找得回**：换模型之后我要把之前聊的重新读一遍，那一遍里图片只剩一个位置标记——但标记上带着它在你本机的路径，我需要看哪张就按路径读回哪张，不用你重新贴一遍。（不会把历史上所有图无差别地重看一遍，那样纯属浪费。）

**怎么用**：给我看图有两条路——📎 / 粘贴 / 拖入把图发进对话（配文字 ⌘Enter 发出），或直接告诉我某张本地图的位置让我自己读。
