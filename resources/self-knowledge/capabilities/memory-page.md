已经没有单独的「主页」了：开屏落在手账——最上面是启动器（我的头像、一句欢迎、新对话输入栏、最近对话），往下滚是这份手账。顶栏「手账」入口随时来看手账，不会打断你正在进行的对话：看完点「对话」就回到刚才聊到一半的地方，上次聊的那个对话重启后也还在。想开一段新对话，点「新建对话」——落到顶部起手台面，往下滚一样能翻到这份手账。手账分几节：

- **昨夜**：我最近一篇夜间整理（dream）的全文，可展开当晚明细，也能翻往期几篇。
- **关于你 / 关于我**：各自打开是只读的一张完整档案（便于好好读），点右上角「编辑」进入自由 markdown 就地编辑——格式随你，写满或只留几句都行，光标所在行会露出 markdown 语法。停手或失焦后自动落盘，不需要手动保存。改完点「完成」留下一条历史版本；点「取消」或关浮层前会询问是否放弃，确认后整篇回退到你开始编辑前那版。右上角「历史版本」能翻旧版、还原——只记你完成过的编辑和我补充过的改动，打字中途不进历史。
- **正在做的**：手上各项目一行一条（项目名 + 一句进展 + 最近活动），点开看项目详情，还能直接「开工」切到该项目开始对话。
- **笔记**：最近几条记忆，按类型（事实 / 约定 / 项目 / 反思 / 线索）着色；可按类型或标签筛选、翻更早的、查看被整理掉的。点一条看详情——正文、标签、来源对话、以及它怎么一步步演化成现在这样。

标题行的头像 hover 出铅笔可改称呼 / 换头像（你和我各一套）。

**限制**：笔记和夜记的正文由我执笔、只读（要改我的认知就在对话里跟我说）；项目列表里一行一条的进展简介是我写的，但打开项目详情看到的项目档案整篇你可以自己编辑。删除某条记忆后它不再以任何方式被想起——删了就是忘了。

**怎么用**：开屏（或顶栏「手账」）落在手账顶部，往下滚按节查看；点「展开」/ 某条笔记 / 某个项目看全文浮层；三处档案（关于你 / 关于我 / 项目档案）浮层打开后点「编辑」进入自由 md 就地编辑，和文档编辑走同一套实时保存 + 历史。
