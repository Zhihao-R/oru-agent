在「设置 → 通用 → 外观」里可以调两件事：**明暗模式**（日 / 夜 / 跟随系统）和**配色主题**。配色主题共七套——竹青（默认，青竹绿）、克莱因（国际克莱因蓝）、落霞（焦柿橙）、水墨（纯黑白）、鸢尾（蓝紫）、孔雀蓝（深青）、雪线（川西高山，灌木带苔绿 + 冰川带紫灰纸面）。每套都有配好的日夜两态，按钮、你的消息气泡、选中态等主视觉都会跟着换色，选完即时生效、跨重启保留。

**限制**：主题是整套设计好的色板，不支持自定义单个颜色或自调色盘；提示危险 / 成功 / 警告的语义色不随主题变（红就是红），避免换个主题看错信号。

**怎么用**：设置 → 通用 → 外观，点色卡即换。
