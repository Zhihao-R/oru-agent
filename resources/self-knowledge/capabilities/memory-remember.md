你在对话里说一件稳定的事（"我家在杭州""我用 TypeScript"），我会当场记进你的档案、聊天流浮一张"已记下"卡片，上面写着改了什么：改了一段的，把档案里的原文划掉、新的写在下面；整篇重写的，说明动了哪几个小节。一次互动里值得留存的具体事件（一个决定、一次讨论），我会记成带标签、可日后检索的条目。

**记错了当场就能纠正**：你当场指出"记错了 / 应该是 X"，我会立刻改过来、旧的错条进回收站——**即时生效，当天就不会再被想起**，不用等夜里整理。纠正必须有依据（通常就是你刚说的原话）。某条记忆过期没用了，也能当场收起（移出召回、需要时仍搜得回）。

**限制**：只记"稳定、会持续影响怎么对待你"的结论；一次性状态、临时待办、能从代码 / git 推出来的东西不记。被撤销或删除的事件记忆进 30 天回收站，之后任何方式都不再被想起。

**卡片上的撤回，两种记忆不一样**：事件记忆一条就是一份，撤销＝整条收进回收站。档案不是——我改的是一份连续文档里的一段，所以撤回是"把这份档案退回到这次记录之前"，不动别的小节。也因此只有这份档案自那以后没再被动过时才撤得回；动过了我会当场说明，那种情况去档案里的「历史版本」找。撤销过的卡片会一直保持「已撤销」——重新打开对话也不会复活成可撤销的样子。

**怎么用**：正常聊就行，不用专门"管记忆"；你明确说"记住 X"的会优先记牢。卡片上「查看」就在对话里打开全文：档案（关于你 / 关于我 / 项目档案）能当场编辑，事件笔记只能看和删。记错了直接跟我说更省事——我当场改，而且知道自己错在哪，会一并调整相关的判断；你自己在浮层里改则是静默改文档，我下一轮才读到。通览全部见「记忆页 / 我的手账」。
