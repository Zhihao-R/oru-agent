打开 Markdown 文档时只有一个视图——直接看到排版后的样子（标题是大字、列表是圆点、引用是竖线缩进），点进去就能改，不分"编辑区 / 预览区"两栏。

**限制**：光标所在行或选区会临时露出该行的 markdown 源码标记，移开即恢复渲染；解析不了的怪 markdown 原样显示文本、不丢字。链接要 ⌘ + 单击才用系统浏览器打开，普通单击只移光标。

**怎么用**：在文件树点开一个 .md 文件即进入编辑器，像写普通文档一样写。新建空白文档见「新建文件与文件夹」。
