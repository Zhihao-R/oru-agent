设置「平台连接」里填好凭证（飞书 App ID + App Secret / Discord Bot Token）并指定一个「远程默认 Oru」后，你在飞书或 Discord **私聊**发消息，桌面就自动出现一个对应会话（「飞书 · 私聊」/「Discord · 私聊」），我在里面接着干活：同一记忆、同一项目、同一上下文，回到桌面能看到全部内容、接着往下聊。收到消息我会先贴「处理中」表情（飞书贴 OnIt、Discord 贴 👀，等我把这条处理完、回复发出去才撤），回复在每段完成后发回，超长自动分段、代码块不会从中间截断；飞书里的回复按 Markdown 渲染（加粗 / 标题 / 列表）。飞书里你还能直接发图给我看。

我正忙时你发来的远程消息不会撞上「正忙」报错，也不再是「最多等一会儿、超时可能起不来」——它和桌面消息走的是**同一条准入队列**：安全的间隙里插进当前回合，或排队等这一回合结束。甚至你在飞书发的话和桌面上另一句话可以**合并进同一个回合**一起处理，回复照样发回飞书——回发只认「这条回复的回合里有没有你的渠道消息」，不在乎这回合是谁起的。

**限制**：只做和我的一对一私聊，不进群聊 / 服务器频道。Discord 收不了图（入站图片只有飞书接了）；看图还依赖当前模型支持视觉，不支持时我会直说。贴纸 / 语音 / 文件这类消息我看不了，会回一句不支持。斜杠命令：`/stop`（立刻叫停我正在跑的活）、`/mode danger｜work｜readonly`（远程切换安全挡位）、`/new`（把当前这段归档、下条消息起开新篇——我正在跑活时会拒绝并提示先 /stop）、`/compress`（别名 `/compact`，立刻手动压缩当前会话上下文）、`/model`（回编号模型清单，`/model 编号` 切换——切的是全局主对话模型，所有主对话含桌面一起换，下一轮才生效）、`/status`（回当前状态：绑定的 Oru、挡位、在用模型、忙闲与排队条数）、`/help`（回这份命令清单）。我远程做出的文件产物（如导出的 PDF）不会作为附件发回平台，要回桌面拿。

**前提**：桌面应用得开着——我在你电脑上，没有云端常驻，应用没开就收不到消息。首次要绑定：设置里生成一次性配对码（限时），你在平台私聊里把码发给我，回「绑定成功」即绑进白名单；还没绑定的人发消息，我会回一句「您尚未通过 Oru 认证」并提示去桌面生成配对码（同一发信人限频，避免刷屏；发错码也是这同一句，不会告诉对方码对不对）。白名单在「设置 ▸ 平台连接」里能看到和管理：每条显示来源平台、绑定时间，绑定时若开了飞书通讯录读取权限还会显示你的昵称（没开就显示用户 ID），可随时移出（移出后需重新配对）；也能直接粘一个用户 ID 手动加进来。**清除某平台的凭证（换 / 解绑应用）会一并清掉该平台已认证的用户**——因为换了应用后这些人的 ID 与聊天地址都随之作废，留着也认不出、发不到，需在新应用下重新配对。破坏性操作守的是这个 Oru 自己的安全挡位——和你在桌面给它设的是同一个；挡位不够我不闷头挂起，会回一句让你把挡位调高再继续——你直接在平台回 `/mode danger` 就能切，改的是那同一个全局挡位（桌面会同步）。

**怎么用**：设置 ▸ 平台连接，填凭证、指定远程默认 Oru、生成配对码绑定，然后去飞书 / Discord 私聊我。
