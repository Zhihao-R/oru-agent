我记得你的一切，全靠本地磁盘上那几份数据——记忆、每场对话、日程与投递账、后台任务、文件的历史版本、你给的信任与项目归属。这些是「我」的全部物理存在，磁盘坏了、机器换了，就得能带着走。设置 → 数据 → 备份与还原里有两个动作：

- **整体导出**：把上面这些不可再生的数据一次打成一个备份文件（`.zip`），你选存到哪。系统自己知道它们全在哪，不用你按目录清单手抄（那样必然抄漏）。
- **从备份还原**：换了新电脑装上应用，指向这个备份文件，我就完整复活——记得所有约定、接得上每场对话、守着全部日程、留着每一版文件历史。备份来自旧版应用也没关系，还原时自动升级格式。

**密钥怎么处理**：导出时有个「包含 API 密钥」的开关，默认关。关着时备份里不含可直接盗用的密钥，换机还原后你重新粘贴一次即可——这样备份文件即便外泄也不会漏钥。开着时密钥明文进包、还原即用，但要自己保管好这个文件（发邮件、存网盘都等于把密钥一起交出去）。

**还原是覆盖，不是合并**：它会用备份里的数据替换掉当前这台设备上的全部数据，所以动手前我会先把当前数据自动兜底备份一份（万一还原有问题能退回去），并弹一次确认；还原完成后应用会重启。

**限制**：
- 厂商侧的「会话影子」（如托管后端的会话编号）不进备份——它随时能由本地历史重建，换机后自动重来，不算数据丢失。
- 目前是手动导出、存本地文件；「定期自动备份」「异地/云同步」还没做。
- 无系统钥匙串的环境里，密钥在本机也只能明文保管（正常的 macOS/Windows 会用系统级加密）。
